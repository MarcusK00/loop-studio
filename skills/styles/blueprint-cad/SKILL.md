# Style Pack: `blueprint-cad` (Technical Schematic & Planetary Linkages)

`blueprint-cad` draws a cyan-on-Prussian-blue (or dark slate) drafting table with major/minor coordinate grid lines, an epicyclic gear/cam mechanism rotating at exact integer harmonic ratios (`1x`, `-2x`, `3x`), dynamic dimension callouts, and cyclic angle telemetry.
